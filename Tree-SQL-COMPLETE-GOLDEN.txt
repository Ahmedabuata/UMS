================================================================================
ENUM MAPPING RULE - CRITICAL - DO NOT PERSIST NUMERIC TO VARCHAR
================================================================================
Rule: Enum numeric values (1,2,3...) are internal C# values only.
DB column VARCHAR stores canonical string: 'ENROLLED' not 1.
EF Core MUST use:
  builder.Property(e => e.Status)
    .HasColumnName("status")
    .HasConversion(
        v => v.ToString(), // C# ENROLLED -> DB 'ENROLLED'
        v => (EnrollmentStatus)Enum.Parse(typeof(EnrollmentStatus), v)
    );

- EnrollmentStatus: ENROLLED, DROPPED, WITHDRAWN, COMPLETED, FAILED -> course_enrollments.status CHECK
- StudentStatus: ST_ACTIVE, ST_INACTIVE, ST_GRADUATED, ST_SUSPENDED -> students.status CHECK
- AcademicStanding: GOOD_STANDING, PROBATION, SUSPENDED, HONORS, DEANS_LIST -> academic_records.academic_status CHECK
- PaymentMethod: CASH, CARD, BANK_TRANSFER, ONLINE -> payments.payment_method CHECK (exact 4)
- GradeLetter: A, B, C, D, F, I, W -> grades.letter_grade CHECK
- FinancialRecordStatus: ACTIVE, CLOSED, OVERDUE -> financial_records.status
- RefundStatus: PENDING, APPROVED, REJECTED -> financial_refunds.status
- GraduationStatus: PENDING, APPROVED, REJECTED, CLEARANCE_PENDING -> graduation_requests.status
- ClearanceStatus: PENDING, APPROVED, REJECTED -> graduation_requests.clearance_status
- NotificationType: INFO, WARNING, SUCCESS, ERROR -> system_notifications.notification_type
