01 — 🐙 ما هو GitHub؟

🐙 GitHub — منصة استضافة الكود
GitHub هو أكبر موقع في العالم لاستضافة ومشاركة الكود. يعمل كـ سحابة لمشاريع Git.

🎯 ماذا يوفر GitHub؟

  • تخزين سحابي لمشاريعك (بدل USB أو قرص صلب).
  • تعاون مع فرق العمل من أي مكان.
  • أتمتة المهام (اختبارات، فحوصات أمنية).
  • إدارة الإصدارات (Versions, Releases).
  • أمان متقدم (Advanced Security).
🚗 تشبيه بسيط

تخيل أن Git هو السيارة، وGitHub هو الجراج السحابي حيث تحفظ وتشارك سيارتك.

02 — ⚖️ Git vs GitHub

هذان مصطلحان مختلفان، وكثير من المبتدئين يخلطون بينهما.

GitGitHub
نظام تحكم بالإصداراتمنصة استضافة سحابية
يعمل بدون إنترنتيحتاج إنترنت
أداة برمجيةخدمة ويب
محلي على جهازكعلى سيرفرات GitHub
مجاني ومفتوحمجاني مع حدود
📌 مثال عملي
  • Git: عندما تكتب git commit -m "..." على جهازك.
  • GitHub: عندما تكتب git push origin main لرفعها للسحابة.

03 — 🚀 الخطوات الأولى

إذا كنت مبتدئاً تماماً، اتبع هذه الخطوات بالترتيب:

1️⃣ إنشاء حساب GitHub
اذهب إلى github.com → Sign up → املأ البيانات → اختر اسم مستخدم جيد.
2️⃣ تثبيت Git على جهازك
حمّل Git من git-scm.com → ثبّته → افتح Terminal واكتب git --version.
3️⃣ تثبيت GitHub Desktop
حمّل GitHub Desktop من desktop.github.com → واجهة رسومية سهلة.
4️⃣ إنشاء أول Repository
في GitHub: زر New → اكتب اسم → اختر Public/Private → Create.
5️⃣ أول Push
في PowerShell: 
git init
git add .
git commit -m "First commit"
git branch -M main
git remote add origin https://github.com/username/repo.git
git push -u origin main

04 — 🗂️ جميع أقسام GitHub

عند فتح أي مستودع، ستجد شريط تنقل بالأقسام التالية:

📁 Code
الكود — الصفحة الرئيسية. تُظهر كل الملفات والمجلدات. من هنا تنزّل، تعدّل، وترفع الكود.
⚠️ Issues
المشاكل — نظام تتبع للأخطاء والمهام والاقتراحات. أي شخص يفتح "Issue" لوصف مشكلة أو فكرة.
🔀 Pull Requests
طلبات الدمج — عندما تُعدّل الكود، تفتح PR لطلب دمجه في main. يمكن للآخرين مراجعته.
⚙️ Actions
الأتمتة — تشغيل المهام تلقائياً (اختبار، فحص أمني، نشر). هذا هو أساس CI/CD.
📊 Projects
إدارة المشاريع — لوحة Kanban لتنظيم المهام (مثل Trello).
🛡️ Security
الأمان — تنبيهات Dependabot و Code Scanning و Secret Scanning.
📈 Insights
التحليلات — إحصائيات المشروع (المساهمون، Commits، Dependency Graph).
⚙️ Settings
الإعدادات — تعديل المستودع (الاسم، الوصف، الحماية، الأمان المتقدم).
🛡️ Security and quality
الأمان والجودة (نسخة محدثة) — يجمع كل التنبيهات الأمنية في صفحة واحدة.
🤖 Agents
الوكلاء (ميزة جديدة) — وكلاء GitHub الذكية لأتمتة المهام.
💡 ملاحظة

لا تُظهر كل المستودعات كل هذه الأقسام. بعضها يظهر حسب إعدادات المستودع.

05 — ⚙️ GitHub Actions

⚙️ GitHub Actions
ما هو؟ نظام أتمتة يعمل داخل GitHub. يمكنه تشغيل أي شيء: اختبارات، فحوصات أمنية، نشر، إلخ.

🎯 كيف يعمل؟

  1. تُنشئ ملف .yml في .github/workflows/.
  2. تحدد متى يعمل (on: push).
  3. تحدد الخطوات (steps).
  4. GitHub يشغّلها تلقائياً على سيرفراته.

مثال بسيط:

name: My First Workflow

on:
  push:
    branches: [main]

jobs:
  hello:
    runs-on: ubuntu-latest
    steps:
      - name: Say Hello
        run: echo "Hello GitHub Actions!"
✅ أمثلة على استخدامات
  • CI/CD: اختبار الكود تلقائياً عند كل Push.
  • Security: فحص الأسرار (Gitleaks, TruffleHog).
  • Container: بناء وفحص صور Docker.
  • Deploy: نشر المشروع على السيرفرات.

06 — 🛡️ ما هو DevSecOps؟

🛡️ DevSecOps
Development + Security + Operations = دمج الأمان في كل خطوة من دورة حياة التطوير.

🎯 الفكرة الأساسية

في الماضي، كان الأمان يأتي بعد تطوير الكود. الآن، مع DevSecOps، يُدمج الأمان في كل خطوة:

المرحلةالنشاط الأمني
كتابة الكودفحص الكود بـ SAST
الرفع إلى Gitفحص الأسرار (Gitleaks)
البناءفحص المكتبات (SCA)
بناء Dockerفحص الحاوية (Container Scanning)
النشرفحص التطبيق (DAST)
بعد النشرمراقبة مستمرة
💡 لماذا مهم؟
  • إصلاح الثغرة في التطوير أرخص 100 مرة من بعد الإطلاق.
  • الأمان يصبح مسؤولية الجميع، وليس فريق واحد.
  • يكتشف الثغرات قبل وصولها للإنتاج.

07 — 🤔 هل GitHub هو DevSecOps؟

⚠️ سؤال شائع جداً

لا، GitHub ليس DevSecOps. لكنه منصة تُتيح تطبيق DevSecOps.

🎯 التوضيح:

الجانبGitHubDevSecOps
ما هو؟منصة استضافة كودفلسفة وممارسات
النوعأداةممارسة
العلاقةيُستخدم لتطبيق DevSecOpsيُطبَّق على GitHub
🚗 تشبيه بسيط

GitHub = المصنع (المكان).
DevSecOps = خط الإنتاج الآمن (العملية).
المصنع يمكنه تشغيل خط إنتاج آمن، لكنه ليس خط الإنتاج نفسه.

🎯 ماذا يوفر GitHub لـ DevSecOps؟

09 — 🛡️ GitHub Advanced Security

GitHub Advanced Security (GHAS) هو مجموعة أدوات أمان متقدمة من GitHub تساعدك على:

  • اكتشاف الثغرات في الكود والمكتبات.
  • منع رفع الأسرار (كلمات مرور، API keys) بالخطأ.
  • تحديث المكتبات تلقائياً لسد الثغرات.
  • فحص الكود بحثاً عن مشاكل أمنية.
✅ مهم لمشروعك

بما أن مستودعك عام (Public)، فأنت تحصل على كل هذه الميزات مجاناً! 🎉

📌 كيف تصل إليها؟
Settings → Security & quality → Advanced Security

13 — 🤖 Dependabot

🤖 Dependabot
ما هو؟ بوت يراقب مكتباتك، ويُنبّهك أو يُحدّثها تلقائياً.

الفائدة:

  • يراقب المكتبات على مدار الساعة.
  • يُنبّهك فوراً عند اكتشاف ثغرة (CVE).
  • يُصلح الثغرات تلقائياً عبر PRs.

29 — 📄 قوالب YAML جاهزة

📄 1. dependabot.yml

version: 2
updates:
  - package-ecosystem: "nuget"
    directory: "/Identity.Microservice/src/Identity.Api"
    schedule:
      interval: "weekly"
      day: "monday"
    open-pull-requests-limit: 5
    labels:
      - "dependencies"
      - "security"
    groups:
      microsoft:
        patterns:
          - "Microsoft.*"

  - package-ecosystem: "npm"
    directory: "/identity-web"
    schedule:
      interval: "weekly"
    labels:
      - "dependencies"
      - "frontend"

  - package-ecosystem: "docker"
    directory: "/Identity.Microservice"
    schedule:
      interval: "weekly"

📄 2. dependency-submission.yml

name: Dependency Submission (NuGet)

on:
  push:
    branches: [main]
    paths:
      - 'gateway/**'
      - 'HR.Microservice/**'
      - 'Identity.Microservice/**'
      - 'identity-web/**'
  workflow_dispatch:

permissions:
  contents: write

jobs:
  dependency-submission:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-dotnet@v4
        with:
          dotnet-version: '8.0.x'
      - name: Submit Gateway dependencies
        uses: advanced-security/component-detection-dependency-submission-action@v0.0.2
        with:
          directory: './gateway'
      - name: Submit HR.Microservice dependencies
        uses: advanced-security/component-detection-dependency-submission-action@v0.0.2
        with:
          directory: './HR.Microservice'
      - name: Submit Identity.Microservice dependencies
        uses: advanced-security/component-detection-dependency-submission-action@v0.0.2
        with:
          directory: './Identity.Microservice'

30 — 🛡️ Branch Protection Rules

Branch Protection هي مجموعة قواعد تحمي الفروع المهمة (مثل main) من التعديلات غير المرغوبة.

🔗 الرابط المباشر
https://github.com/Ahmedabuata/UMS/settings/branches

🎯 كل خيار وشرحه:

الخيارالمعنىالتوصية
Require a pull request before mergingيمنع الدفع المباشر إلى main.✅ مُفعّل
Require approvalsيطلب موافقة شخص آخر على PR.❌ معطّل (لأنك وحدك)
Dismiss stale approvalsإلغاء الموافقات عند إضافة تعديلات.✅ مُفعّل
Require review from Code Ownersيطلب موافقة من CODEOWNERS.❌ (يحتاج Pro)
Require status checks to passيمنع الدمج حتى تنجح الفحوصات.✅ مُفعّل
Require branches to be up to dateيجب تحديث الفرع مع main.✅ مُفعّل
Require conversation resolutionحل كل التعليقات قبل الدمج.✅ مُفعّل
Require signed commitsتوقيع رقمي على Commits.❌ (معقد)
Require linear historyيمنع Merge Commits.✅ مُفعّل
Do not allow bypassingالجميع يخضع للقواعد.✅ مُفعّل
Allow force pushesالسماح بـ Force Push.❌ معطّل
Allow deletionsالسماح بحذف الفرع.❌ معطّل
⚠️ لماذا عطّلنا Require approvals؟
  • أنت المساهم الوحيد في المستودع.
  • لا يوجد شخص آخر يمكنه الموافقة.
  • لو فعّلناه، ستتجمد كل PRs.

34 — 🚨 Advanced Security Alerts

Advanced Security Alerts هي التنبيهات التي تظهر في صفحة Security عند وجود مشاكل أمنية.

🎯 أنواع التنبيهات:

📦 Dependabot Alerts
ما هو؟ تنبيهات عن ثغرات في المكتبات (NuGet, NPM, Docker).
المكان: Security → Dependabot
الخطورة: Critical, High, Medium, Low
الحالة عندك: ✅ 3 تنبيهات
🔍 Code Scanning Alerts
ما هو؟ تنبيهات عن ثغرات في الكود (من CodeQL).
المكان: Security → Code Scanning
الحالة عندك: ✅ 17 تنبيه
🔐 Secret Scanning Alerts
ما هو؟ تنبيهات عن أسرار مكشوفة.
الحالة عندك: ⚠️ (يجب التحقق)
🦠 Malware Alerts
ما هو؟ تنبيهات عن برامج خبيثة في المكتبات.
الحالة عندك: ✅ (لا شيء حالياً)

📊 ملخص الحالة عندك:

النوعالعددالإجراء
Dependabot Vulnerabilities3مراجعة وإصلاح

Malware0✅ نظيف
